## 킹 레거시 4월 코드 — 지금 바로 쓰세요!

킹 레거시(King Legacy)에서 쓸 수 있는 **무료 코드 8개**를 4월 기준으로 싹 정리했어요. 코드는 유효기간이 있으니 빨리 입력할수록 좋아요!

### 현재 활성 코드 목록

| 코드 | 보상 |
|------|------|
| **FREESTATSRESET** | 무료 스탯 리셋 |
| **FreePterSpin** | 무료 프테라 스핀 |
| **DragonColorRefund** | 드래곤 컬러 환불 |
| **SORRYFORDELAY** | 보석 보상 |
| **KLEGACY1BILLION** | 보석/경험치 |
| **UPDATE5** | 보석 |
| **RELEASE** | 보석 |
| **THXFOR500M** | 보석 |

### 추천 사용 순서

> 스탯 리셋 → 프테라 스핀 → 드래곤 컬러 환불 → 나머지 보석 코드 순으로 입력하세요!

1. **FREESTATSRESET** 먼저 — 스탯을 잘못 찍었다면 완전 무료로 초기화 가능해요. 로벅스(Robux·게임 내 유료 화폐)로 사면 수천 원인데 공짜!
2. **FreePterSpin** — 프테라 과일(Pterodactyl Fruit) 스핀 기회. 희귀 과일 획득 확률 있음.
3. **DragonColorRefund** — 드래곤 컬러(Dragon Color·외형 변경) 환불 코드. 드래곤 과일 유저라면 필수.

### 코드 입력 방법

1. 게임 접속 후 화면 왼쪽 **메뉴** 클릭
2. **Codes** 버튼 선택
3. 코드 입력 후 **Enter**
