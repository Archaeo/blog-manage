## 머더 미스터리 2 코드 — 4월에 쓸 수 있는 거 다 모았어요!

머더 미스터리 2(Murder Mystery 2·MM2)는 살인범·탐정·무고한 시민 역할을 맡는 로블록스 인기 게임이에요. 코드를 입력하면 **무기 스킨(Weapon Skin)** 이나 **나이프 스킨(Knife Skin)** 을 무료로 받을 수 있어요!

### 스킨 가치 분석

- MM2 마켓플레이스(거래소)에서 희귀 나이프 스킨은 **수백~수천 MM2 Value** 수준
- 코드로 받는 스킨은 직접 거래 또는 보유 용도로 활용 가능
- 로벅스(Robux)로 스킨을 살 경우 개당 수백~수천 원 상당이라 무료 코드 가치가 상당해요

### 코드 입력 방법

1. 로비 화면에서 **인벤토리(Inventory)** 아이콘 클릭
2. **Redeem** 탭 선택
3. 코드 입력 후 확인
