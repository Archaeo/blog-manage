## 추천 사용 순서

코드가 아주 많으니까, **이 순서대로 먼저 입력하는 걸 추천**해요!

1. **최신 코드 먼저** — `LUNAR_2026`, `2M_FAVS`, `96_PERCENT` 같은 최신 코드는 만료 가능성이 가장 낮아요
2. **셧다운 보상 코드** — `MECH_SHUTDOWN`, `SOUL_SHUTDOWN`, `FUGA_SHUTDOWN` 등은 보상이 큰 편이에요
3. **기술 출시 코드** — `SIX_EYED_CALAMITY`, `ANCIENT_CONSTRUCT`, `PROJECTION_OUT`은 새 기술 출시 기념이라 보상이 좋을 가능성이 높아요
4. **마일스톤 코드** — `2M_FAVS`, `1M_FAVORITES`, `50K_FOLLOWERS`는 달성 기념이라 후한 보상이 기대돼요
5. **이벤트 코드** — 시즌이 지난 코드(`MERRY_CHRISTMAS`, `HAPPY_2025` 등)는 만료됐을 수 있으니 마지막에 시도해요
6. **미확인 코드** — 안 되면 말고! 한번씩 넣어보세요

## 코드 입력 방법

1. 주츠 인피니티 게임에 접속해요
2. 화면 왼쪽에 있는 **메뉴 버튼**을 눌러요
3. **코드 입력창**을 찾아서 코드를 정확히 입력해요
4. **대소문자와 언더바(_)를 정확하게** 입력해야 해요!

> 코드 입력 시 **대소문자 구분**이 중요해요! `LUNAR_2026`과 `lunar_2026`은 다른 코드로 인식될 수 있어요.
