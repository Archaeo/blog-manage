## 올스타 타워 디펜스 4월 코드 총정리

올스타 타워 디펜스(All Star Tower Defense·ASTD)에서 코드를 입력하면 **보석(Gems)** 을 무료로 받을 수 있어요. 보석은 새 유닛을 뽑는 데 꼭 필요한 재료예요!

### 활성 코드 목록

| 코드 | 보상 |
|------|------|
| **ASTDUPDATE** | 보석 150개 |
| **THANKYOU100M** | 보석 150개 |
| **SORRYFORWAIT** | 보석 100개 |
| **NEWYEAR2026** | 보석 100개 |
| **HAPPYHOLIDAYS** | 보석 75개 |
| **FREEGEMASTD** | 보석 50개 |
| **WELCOMEBACK** | 보석 50개 |
| **ASTDLAUNCH** | 보석 30개 |

> 코드를 전부 입력하면 총 **보석 705개** 이상을 무료로 받을 수 있어요!

### 보석 가치 분석

- 보석 150개 = 일반 소환 약 15회 분량
- 유료 보석 패키지 기준, 150개는 **약 2,000~3,000원** 상당의 가치
- 코드로 얻는 보석 합산 시 무료 소환 수십 회가 가능해요

### 코드 입력 방법

1. 메인 화면 좌측 하단 **Twitter(X) 아이콘** 클릭
2. 코드 입력란에 코드 붙여넣기
3. **Redeem** 버튼 클릭
