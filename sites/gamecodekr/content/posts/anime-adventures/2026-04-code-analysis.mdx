## 이번 달 코드 총 가치

2026년 4월 애니메 어드벤처에서 확인된 코드는 **1개**, 확인 중인 코드는 **11개**예요.

애니메 어드벤처 코드는 보통 **젬(Gems)**이나 **티켓(Tickets)**을 줘요. 젬은 배너 뽑기(가챠)에 쓰이고, 티켓은 특별 유닛을 소환할 때 필요해요. 둘 다 게임에서 강해지려면 꼭 필요한 재화(게임 돈)예요.

현재 대부분의 코드가 보상 확인 중이라서, 정확한 총 가치는 확정하기 어려워요. 새로운 정보가 나오면 바로 업데이트할게요!

## 확인된 코드 상세 분석

### SACREDPLANET

- **상태:** 작동 확인됨
- **추가된 날짜:** 2026년 4월 3일
- **예상 보상:** 젬 또는 티켓 (정확한 수량 확인 중)

"Sacred Planet(성스러운 행성)"이라는 이름의 기념 코드예요. 애니메 어드벤처에서 새 이벤트나 업데이트가 나올 때 이런 코드가 등장하는 경우가 많아요.

> 작동이 확인된 유일한 코드이니, **가장 먼저 입력하는 것을 추천**해요!

## 보상 가치 예상

애니메 어드벤처의 일반적인 코드 보상 패턴을 참고하면:

- **젬 코드:** 보통 50~200젬을 줘요. 젬 200개면 배너 뽑기 약 2~3회 가능!
- **티켓 코드:** 스타더스트 티켓이나 레이드 티켓을 줄 수 있어요
- **기념 코드:** 마일스톤 기념 코드(MILLIONFAVES, 2BILLIONAA)는 평소보다 보상이 넉넉한 경우가 많아요

> 아직 보상이 확정되지 않은 코드가 많아요. 위 내용은 코드 이름과 기존 패턴을 바탕으로 한 예상이에요.
