## 이번 달 코드 총정리

2026년 4월 타워 디펜스 시뮬레이터(Tower Defense Simulator)에서 확인된 코드는 총 **29개**예요. 다만 대부분의 코드가 아직 보상이 정확히 확인되지 않은 상태라서, 확인되는 대로 업데이트할게요.

## 보상 확인된 코드 상세 분석

### DOUBLEBLOXIES — 블록시(Bloxies) 2배

- **보상:** 블록시 획득량 2배
- **가치:** 블록시는 TDS에서 타워 업그레이드나 아이템 구매에 쓰이는 재화(게임 돈)예요. 2배 부스트는 같은 시간에 2배로 모을 수 있으니 매우 유용해요!
- **추천 타이밍:** 긴 게임을 시작하기 직전에 입력하세요

### resetModifier — 모디파이어(Modifier) 리셋

- **보상:** 모디파이어 초기화
- **가치:** 모디파이어는 게임 난이도를 바꿔주는 설정이에요. 잘못 설정했을 때 리셋할 수 있으니, 필요할 때 써두면 좋아요
- **추천 타이밍:** 모디파이어 설정을 잘못했을 때 사용

## 코드 입력 방법

1. 타워 디펜스 시뮬레이터 게임에 접속해요
2. 로비(게임 시작 전 대기 화면)에서 **트위터(X) 아이콘**을 찾아 클릭해요
3. 코드 입력창에 코드를 **정확하게** 입력해요 (대소문자 구분!)
4. 확인 버튼을 누르면 보상이 지급돼요

## 추천 사용 순서

1. **DOUBLEBLOXIES** — 블록시 2배 부스트를 먼저 켜고 게임을 시작하세요
2. **resetModifier** — 모디파이어를 잘못 설정했을 때만 사용하세요
3. **나머지 미확인 코드들** — 하나씩 입력해보세요. 만료된 코드는 "유효하지 않은 코드"라고 뜰 거예요
